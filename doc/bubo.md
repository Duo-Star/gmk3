# 核心
这是一个专属于射影几何的形式化证明推导器
用户可以用 dsl 表达几何结构，然后把待证明的结论放在最终，机器会依照给定的条件按照已知的定理库一步步推演匹配搜索，直到目标出现，然后把证明过程返回给用户
我加入了更利于表达和演算的创新性元素


# 复生对象

## 骈点
即一对点
骈点 `dD` 由 `{D1, D2}` 组成，彼此不区分


## 合点
即一对骈点
合点 `qD` 由 `{dD1, dD2}` 组成，彼此不区分
设 `dD1` 由 `{D11, D12}` 组成，`dD2` 由 `{D21, D22}` 组成
则

| 方法写作        | 描述       | 解释                                                                                                    | 类型    |
| ----------- | -------- | ----------------------------------------------------------------------------------------------------- | ----- |
| `ctr qD D`  | 合点的 `心点` | `直线{D11, D12}` 和 `直线{D21, D22}` 的交点                                                                   | 点     |
| `der qD dX` | 合点的 `骈叉` | `叉线 {直线{D11, D21}, 直线{D22, D12}}`<br>和<br>`叉线 {直线{D11, D22}, 直线{D12, D21}}`<br>组成的骈交叉直线               | 骈交叉直线 |
| `der qD dD` | 合点的 `衍点` | `直线{D11, D21} 和 直线{D22, D12} 的交点`<br>和<br>`直线{D11, D22} 和 直线{D12, D21} 的交点`<br>组成的骈点<br>即：合点的骈叉的各自两中心 | 骈点    |
| `der qD L`  | 合点的 `衍线` | 合点的 `衍点` 的连线                                                                                          | 直线    |
|             |          |                                                                                                       |       |
需注意到：`der` 可以根据后面的标签类型来重定向到具体的方法

# 语法
## 类型

| 类型符 | 类型名       | 解释                                                               |
| --- | --------- | ---------------------------------------------------------------- |
| D   | 点         | 取名自：`Dot`                                                        |
| L   | 直线        |                                                                  |
| C   | 圆锥曲线      | 取名自：`Conic`                                                      |
| O   | 圆（C子类）    | 取名自：`O` 长得像圆形                                                    |
| E   | 椭圆（C子类）   | 取名自：`Ellipse`<br>与无穷远线交于两个共轭虚点                                   |
| H   | 双曲线（C子类）  | 取名自：`Hyperbola`<br>与无穷远线**相切**（一个二重实交点）                          |
| P   | 抛物线（C子类）  | 取名自：`Parabola`<br>与无穷远线交于两个实点                                    |
| X   | 交叉直线（C子类） | 取名自：`X` 长得像交叉直线<br>不强调交叉点（有限点）<br>而"一对平行直线"算作：<br>交叉点在无穷远的"交叉直线" |
| dD  | 骈点        | 第一个 `d` 意为 `double` 或 `duo`                                      |
| qD  | 合点        | 第一个 `q` 意为 `quadruple`                                           |
| dX  | 骈交叉直线     | 第一个 `d` 意为 `double` 或 `duo`                                      |
|     |           |                                                                  |

## 标签名
标签名应自带有显式类型标注，允许的形状为（这些都是以 `D` 类型的标签名为例的各式样例）：

| 例                            | 解释         |
| ---------------------------- | ---------- |
| `D1`  或 `D123`               | 类型符紧跟数字    |
| `D_1` 或  `D_A` 或 `D_aBc12_3` | 使用下划线，后面任意 |
例如： `dXL_A1`, `X3`, `E_2`

# 例子

```bubo
tan D1 C1 X1 dD1 // 过 D1 做 C1 的切线得到交叉直线 X1 以及切点（骈点 dD1）
ctr C1 D2        // D2 为 C1 的中心
con D2 dD1 X2    // 连接 D2 以及骈点 dD1 得到交叉直线 X2
->               // 那么
vet X1 X2       // 交叉直线 X1 和 X2 垂直
```


完全四线形-极点-极线
```bubo
pas qD1 C1       // 取一个合点 qD1 在圆锥曲线 C1 上
der qD1 L1       // 合点的衍线为 L1
ctr qD1 D1       // 合点的心点为 D1
->               // 那么
pol D1 C1 L1     // D1 和 L1 关于 C1 互为极点级线
```


极点-极线调和共轭定理
```bubo
pas qD1 C1       // 取一个合点 qD1 在圆锥曲线 C1 上
der qD1 L1       // 合点的衍线为 L1
ctr qD1 D1       // 合点的心点为 D1
pas D1 L2        // 直线 L2 穿过 D1
ins L2 C1 dD1    // 直线 L2 与圆锥曲线 C1 交于骈点 dD1
ins L2 L1 D2     // 直线 L2 与直线 L1 交于点 D2
->
har dD1 D1 D2    // dD1 调和分割 D1 D2
```



切点把“切线和双曲线的渐近线的骈交点”平分
```bubo
pas H1 D1     // 双曲线 H1 上取点 D1 
tan D1 H1 L1  // 过点 D1 做双曲线 H1 的切线 L1
asy H1 X1     // 双曲线 H1 的渐近线为 X1
ins L1 X1 dD1 // 切线 L1 与渐近线 X1 交于骈点 dD1
->
ctr dD1 D1    // 点 D1 为骈点 dD1 的中点
```


共轭直径
```bubo
pas C1 D1      // 圆锥曲线 C1 穿过 D1
tan D1 C1 L1   // 过 D1 做 C1 切线 L1
ctr C1 D2      // D2 为 C1 中心
con D1 D2 L2   // L2 为 D1 和 D2 连线
->
cgd C1 L1 L2   // L1 和 L2 是 C1 的共轭方向
```

共轭平分性质
```bubo
cgd C1 L1 L2   // L1 和 L2 是 C1 的共轭方向
ctr C1 D1      // D1 为 C1 中心
pas L1 D1      // L1 穿过 D1
pll L2 L3      // L2 和 L3 互相平行
ins C1 L3 dD1  // L3 与 C1 交于 dD1
ins L1 L3 D2   // L1 和 L3 交于 D2
->
ctr D2 dD1     // D2 为 dD1 中点
```


直径的定义
```bubo
pll L1 L2      // L1 与 L2 互相平行
ins C1 L1 dD1  // C1 与 L1 交于骈点 dD1
ins C1 L2 dD2  // C1 与 L2 交于骈点 dD2
ctr dD1 D1     // 取骈点 dD1 中点 D1
ctr dD2 D2     // 取骈点 dD2 中点 D2
con D1 D2 L3   // 连接 D1 D2 为直线 L3
->
dia C1 L3      // L3 是 C1 的直径
```

```text
圆锥曲线（图中为椭圆） C0
直线 L1 L1' L2 L2' L3 L3' L4 L4' L5 L5' L6 L7 L8
点 D E F G H I J K L M N O P
.

C0 交 L1' 于 G F

.
连 D F 为 L2
连 E G 为 L2'
L2 交 L2' 为 H
.
连 E F 为 L3
连 D G 为 L3'
L3 交 L3' 为 I
.
D E G F 关于 C0 的极线（或曲线上的单切线）分别为 L4' L4 L5 L5'
.
L5 交 L5' 为 J
L4 交 L4' 为 K
.
L5 交 L4' 为 N
L5' 交 L4 为 M
.
L5' 交 L4' 为 O
L5 交 L4 为 P
.
那么：
H I J K 共线
H I 调和分割 J K
.
H L M N 共线
H L 调和分割 M N
.
I L O P 共线
I L 调和分割 O P

```
